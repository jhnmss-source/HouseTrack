# HouseTrack

*A Rental Property Management System with Payment Monitoring and Repair Request Handling*

Software Engineering 2 | Emilio Aguinaldo College - Cavite | Group 7
Instructor: Arabaca, Henry III

## About

HouseTrack is a web app for small rental owners. It replaces notebooks and chat messages with one system for tracking tenants, units, contracts, rent payments, and repair requests.

Case study: Alano Family Rentals.

## Features

- Login/logout with 3 roles: Owner, System Administrator, Tenant
- Manage units, tenants, and rental contracts
- Record rent payments (paid, unpaid, overdue)
- Payment history and printable receipts
- Tenant repair requests (pending, ongoing, done)
- Owner dashboard and reports
- Search and filter
- Admin: accounts, password reset, settings, logs, backup and restore
